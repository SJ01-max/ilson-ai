## 로드맵 (운영·확장 단계)

- 1단계: 배정 **검토→수정→확정** 워크플로 (확정본 저장·이력·CSV 출력)
- 2단계: 결근·요청 취소 대응 **재배정**
- 3단계: 농가 **요청 등록** 창 (CSV → UI, 상태 저장)
- 4단계: 예보→배정 **연결** (강수일 클릭 → 해당 날짜 보드, QA-08 "부족을 예보로" 와 연결)
- 5단계: 기상 원자료 **적재 축적 → 예보-실황 대조 → 보정계수 재학습** (매일 적재는 가동)
- 6단계: 부족 시 **농가별 최소 1명 보장** 형평성 제약 (QA-10)
- 7단계: 모바일 1024×768 레이아웃 재설계 (QA-27·28·32·33·34·35·38)
- 8단계: 접근성 패스 (QA-37·38)
- 9단계: 운영 이관 — Rate-limit·토큰 만료·입력 검증·테스트 코드 (QA-14·18·19·23)

**원칙**: 측정한 효과만 주장한다 (읍면 일치율을 이동시간 절감으로, 작목 일치율을 작업 효율로 환산하지 않음).
상세 커밋 로그는 `docs/ai-log.md` 참조.
