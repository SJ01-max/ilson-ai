| 번호 | 로드맵 항목 | 이연 사유 |
|---|---|---|
| 1 | 배정 **검토→수정→확정** 워크플로 (확정본 저장·이력·CSV 출력) | 상태 관리와 담당자 UX 설계가 추가로 필요 — 데모 범위 밖 |

| 4 | 예보→배정 **연결** (강수일 클릭 → 해당 날짜 보드) | 좋은 아이디어지만 데모 완성도에 밀림 |
| 5 | 기상 원자료 **적재 축적 → 예보-실황 대조 → 보정계수 재학습** | 자동 적재는 매일 예약 실행 중, 축적 자체가 전제 (데이터 1주 이상 쌓고 분석) |

| 7 | 다중 사용자·역할 분리 | 1인 담당자 시나리오 범위 밖 |
| 8 | 발표 자료의 42인일 → 당일 실예보 숫자로 자동 삽입 | 현재 "10/10 기준 시연 스냅샷" 라벨링으로 대신 처리 |
