## 1. 문제 — 분모 중복집계

보정 전 `share_ratio()`는 담당 비율의 분모로 **작목별 농가 수의 단순 합(= 6,814)**을 썼다.
한 농가가 여러 작목을 재배하면 작목마다 1번씩 세어져 과대평가된다.

```python
# 보정 전 (demand.py)
farms = load_areas().drop_duplicates(["crop", "field_type"]).city_farms.sum()  # 6,814
```

영향: 분모가 커질수록 `담당 비율 = PUBLIC_FARMS ÷ 농가 수`가 과소 산정되어, 전체 수요가 억제됐다
(보정 전 시즌 5~10월 맑은 날 평균 수요 **15.86명 / 20명 ≈ 가동률 79.3%**).

## 2. 수정 — 분모 교체 (6,814 → 2,018)

커밋 114a55c에서 `target_farms()` 신설. 중복 집계가 없는 **영농형태 비중** 방식으로 교체.

```
대상 농가 수 = 2025 농림어업총조사 농가 수 × 2024 영농형태 중 (채소·산나물 + 과수 + 기타작물) 비중
            = 4,277 × (845 + 167 + 422) / 3,039
            ≈ 2,018
```

- 전체 농가 수(**4,277**): `data/KOSIS/farm_size.csv` — 2025 농림어업총조사. 면적 데이터(vegetable·facility·fruit, 2025)와 연도 일관성.
- 비중 분자·분모(**845 / 167 / 422 / 3,039**): `data/KOSIS/farm_types.csv` — 2024 영농형태(주 작목). **1가구 1분류**라 중복 집계 없음.
- 과수(표본오차 30.6%)·기타작물(25.2%)은 단독 사용 시 불안정 → 세 항목 묶음 비중으로 완충.

## 3. 보정 — k = 0.82 (전체 수준만, 원단위는 가정 유지)

`crop_calendar.csv`의 `workers_per_10a`는 **원단위 자체가 전부 "가정값"** 이다 (농진청 농산물소득자료집의 작목별 10a당 노동시간을 확보하지 못함). CSV 의 `basis` 열은 "**가정값(전체 수준은 k=0.82로 역산보정)**" 으로 표기해, "k 로 역산한 것은 전체 수준뿐이고 월별·작목별 상대 강도는 여전히 가정" 임을 명시한다.
개별 값은 바로잡을 수 없으므로 **전체 수준만 한 번** 보정계수 `K`로 축소한다.

```python
# forecast/demand.py L26~L31
# 근거: 보정 전 시즌(5~10월) 맑은 날 평균 수요 15.86명 / 보유 20명 = 가동률 79.3%
#       → 목표 가동률 약 65% 에 맞춰 k = 0.65 / 0.793 ≈ 0.82
K = 0.82
```

- 월별 모양(계절성)은 그대로 두고 크기만 균등 축소 — 작목 간 상대 강도는 가정값 그대로.
- 목표치 65%의 외부 근거(백석농협 공공형 운영 실적 역산 등)는 **(새영 검토 필요)** — 코드·커밋 메시지·주석 어디에도 수치 출처가 남아있지 않음.

### 우리 가정값 산출 방법

`workers_per_10a`는 "그 달 하루에 10a당 필요한 인원"이므로 연간 시간으로 바꾸면:

```
연간 10a당 노동시간 = Σ(1~12월 workers_per_10a) × 8시간 × 25일 = Σ월별값 × 200
```

### 비교 범위가 10월 수요의 94%

`demand_breakdown("2026-10-14", rain=False)` (현재 K=0.82):

```
전체 14.35명, 제외 작목(노지 고추 0.72 + 노지 호박 0.11 + 노지 오이 0.00) = 0.84명
비교한 9개 작목 비중 = (14.35 − 0.84) ÷ 14.35 = 94%
```

### k 재계산: 0.82 → 1.02

9개 작목의 월별 값에 위 비율(농진청÷우리)을 곱하고(월별 모양은 유지), 나머지 3개 작목은 그대로 둔 채 **k=1**로 계산:

```
현재:  보정 전(k=1) 시즌(5~10월) 맑은 날 평균 15.86명 / 20명 = 79.3%  → k = 0.65 ÷ 0.793 = 0.82
대조:  농진청 비율 적용(k=1) 시즌 맑은 날 평균 12.80명 / 20명 = 64.0%  → k = 0.65 ÷ 0.640 = 1.016 ≈ 1.02
```

이 경우(k≈1.02) 10월(2026-10-14) 수요: 맑은 날 15.2명, 비 오는 날 6.0명 (현재 K=0.82: 맑은 날 14.3명, 비 오는 날 8.3명 — 비 오는 날 수요는 시설 작목뿐이라 시설 원단위가 줄어든 만큼 감소).

### 결론

- **전체 수준은 일치**(k≈1): 가정값 + k=0.82로 맞춘 총량이 농진청 공식값과 거의 같다.
- **작목별 상대 강도는 어긋남**: 시설채소·과수는 과대(비율 0.57~0.76), 참깨·들깨는 과소(1.65~1.94). → **본선 후 공식값으로 교체**.
- 교체 후에도 남는 가정: ① 월별 배분(노동투입표는 연간 합계·작업단계별만 있고 월 정보 없음), ② 노지 고추·오이·호박 원단위, ③ 목표 가동률 65%.
